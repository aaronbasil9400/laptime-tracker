# Anti-Slop UI Audit 001

Date: 2026-10-25
Target: `laptime-tracker/index.html`
Mode: AFTER

This audit records design and interaction findings only. No app code was changed. Findings are ordered for review; approve the finding numbers you want addressed before any fixes.

## Findings

1. **HIGH: “Pace gained” can report improvement across unrelated circuits and cars.** (R-17, R-36)
   The summary compares the oldest and newest thirds of all lap times, even when the driver changed circuit, game, or car. The statistic can claim progress that the data does not support. Calculate it within one selected combination or remove the claim.

2. **HIGH: Lap details disappear for keyboard users on desktop.** (R-32)
   Session, conditions, date, class, and notes are hidden until pointer hover. Keyboard focus does not reveal them. Keep essential context visible or reveal it on focus as well as hover.

3. **HIGH: The import panel promises a replace option that does not exist.** (R-38)
   Its heading says “merge or replace,” but the import behavior only merges rows and skips duplicate IDs. Change the label to describe the real behavior or add a clearly separated replace action.

4. **HIGH: “Cancel edit” appears while adding a new lap and can clear the draft.** (R-26)
   The button has the `hidden` attribute, but the `.btn` display rule overrides it. Outside edit mode, its label is inaccurate and clicking it resets the form. Hide it outside edit mode or provide an accurately labeled draft-clear action.
